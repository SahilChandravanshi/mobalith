## Tagline

Master the Meta. Forge Your Victory.

## Goal

Build the best free Mobile Legends companion website.

The project must be:

- Fast
- Lightweight
- Mobile-first
- Installable (PWA)
- GitHub Pages deployable
- 100% free
- Modern
- Apple-inspired UI
- Minimal animations
- Dark mode first
- Easily maintainable
- Modular architecture

## UI Direction

Use MLBBHub as the primary design inspiration.

Do not copy its code or assets.

Instead, create an original UI that captures the same premium gaming aesthetic while improving:

- consistency
- spacing
- typography
- responsiveness
- accessibility
- performance

The UI should immediately feel familiar to MLBB players while remaining uniquely Mobalith.

Use smooth but subtle animations only.

Avoid flashy effects.
